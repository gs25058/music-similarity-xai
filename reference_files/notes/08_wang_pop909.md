# 08. POP909 데이터셋

- **저자:** Ziyu Wang, Ke Chen, Junyan Jiang, Yiyi Zhang, Maoran Xu, Shuqi Dai, Xianbin Gu, Gus Xia. 저자 표기는 원문 PDF 첫 페이지 기준.
- **제목:** POP909: A Pop-song Dataset for Music Arrangement Generation.
- **발표:** ISMIR 2020, pp. 38–45.
- **출처:** [학회 원문](https://archives.ismir.net/ismir2020/paper/000089.pdf) · [저자들의 데이터 저장소](https://github.com/music-x-lab/POP909-Dataset).
- **인용 키:** `wang2020pop909`.

## 확인한 내용

909곡의 피아노 편곡 MIDI에 주선율, 보조 선율, 피아노 반주와 음악 주석을 제공한다. 원문 초록에 따르면 템포 곡선은 수작업 주석이고 다른 주석은 MIR 알고리즘으로 산출된다. 모든 주석을 사람이 검증한 정답이라고 가정하지 않는다. 근거 범위: 학회 PDF 첫 페이지 초록.

## 우리 연구의 활용 제안

특정 요소를 보존하거나 변경한 음악 쌍을 만들어 요소별 반응을 평가한다. 원곡 ID로 먼저 학습·검증·평가 집합을 나눈 뒤 변형을 생성해 같은 곡의 파생본이 집합 간 섞이지 않도록 한다. 음정·리듬·화성 변형이 다른 요소에도 영향을 주는지는 별도로 검사한다.

## 한계

표절 정답이나 실제 베이스 연주 정답을 제공하는 데이터셋이 아니다. 피아노 저음부에서 유도한 베이스는 파생 라벨로 표시해야 한다. MIDI를 음원 인코더 입력으로 쓰려면 렌더링 조건을 고정하고 기록한다. 편곡 도메인에서 얻은 결과의 실제 혼합 음원 일반화도 따로 평가한다. 데이터셋은 이 폴더에 내려받지 않았다.
